The assessment identified weaknesses across Oscorp's according to the NIST 800-53 framework. Key concerns included:

- Undefined cybersecurity governance and accountability
- Enterprise risk management
- Asset and software inventory
- Third-party risk
- Access control
- Data security
- Security monitoring
- Endpoint security
- Incident response
- Digital forensics
- Recovery and crisis communications

The purpose of the register is to convert technical deficiencies into **business risk**. This was the original Capstone Project Task.
