# Technology Evaluation Criteria

Before purchase or renewal, document:

1.  **Gap Traceability** --- Which Gap IDs does the solution address?
2.  **Risk Traceability** --- Which Risk IDs does it mitigate?
3.  **NIST Alignment** --- Does it adequately support the relevant NIST
    CSF outcome?
4.  **Evidence** --- Can Oscorp prove implementation and operating
    effectiveness?
5.  **Residual Risk** --- What likelihood/impact remains after
    implementation?
6.  **Operational Fit** --- Staffing, integration, retention,
    scalability, training, implementation effort, recurring cost and
    exit difficulty.

> **No tool should be approved solely because it advertises NIST,
> compliance or security automation.**

A complete control requires the appropriate combination of **people,
process, technology, governance, evidence and monitoring**.
