# Cybersecurity Team Growth Plan

## Year 1 --- Establish the Security Function

  -----------------------------------------------------------------------
  Role                                Primary Responsibility
  ----------------------------------- -----------------------------------
  **Cybersecurity / GRC Manager**     Program leadership, strategy,
                                      budget planning, NIST
                                      implementation, risk governance,
                                      policies and executive reporting

  **GRC Analyst**                     NIST assessments, risk register,
                                      gap assessments, policies, TPRM,
                                      compliance, control testing and
                                      evidence

  **Security Engineer / IAM           Azure/Entra, MFA, Conditional
  Engineer**                          Access, RBAC, privileged access,
                                      endpoint and security
                                      configurations

  **Security Analyst**                Vulnerability management, endpoint
                                      security, monitoring, detection,
                                      investigation and response
  -----------------------------------------------------------------------

**Team size: 4.** The manager reports to the CTO as executive sponsor.

### Year 1 Salary Assumptions

  Role                                 Estimated Salary
  ---------------------------------- ------------------
  Cybersecurity / GRC Manager                  \~\$145K
  GRC & Risk Analyst                           \~\$100K
  Security Engineer / IAM Engineer             \~\$130K
  Security Analyst                             \~\$105K
